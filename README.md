# TermAI

TermAI - это инструмент командной строки для управления и автоматизации терминальных операций.

## Установка

```bash
go install github.com/dmytrii/termai@latest
```

## Использование

```bash
termai [команда] [опции]
```

## Доступные команды

- `termai run` - Запуск команды
- `termai config` - Управление конфигурацией
- `termai version` - Показать версию

## Конфигурация

Конфигурационный файл находится в `~/.termai/config.yaml`
